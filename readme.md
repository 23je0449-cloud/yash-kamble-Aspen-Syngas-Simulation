# Syngas/Hydrogen Production via Carbon Sacrificial Anode-Assisted Water Electrolysis

This project models **syngas (H₂ + CO) production** using a **self-supporting carbon sacrificial anode-assisted water electrolysis process**, simulated in **Aspen Plus**.

---

## 📌 Project Overview
- **Objective:** To simulate hydrogen and carbon monoxide generation from water electrolysis using a carbon sacrificial anode.  
- **Tool Used:** Aspen Plus (Property Method: ELECNRTL).  
- **Key Focus:** Gas composition analysis in the product streams (H₂ and CO).  

---

## 🛠 Methodology
1. **System Setup**
   - Components included: C, KOH, H₂, O₂, H₂O, CO₂, CO, KHCO₃.
   - ELECNRTL property method applied for electrolytic and ionic systems.
   - Electrolyte Wizard used to define ionic species (H⁺, OH⁻, K⁺).
   
2. **Simulation**
   - Developed the Aspen Plus flowsheet.
   - Entered process data (feeds, thermodynamic parameters).
   - Ran steady-state simulation.

3. **Analysis**
   - Determined gas composition of **H₂** and **CO** streams.
   - Evaluated impact of reaction conditions on syngas ratio.

---

## 📊 Results
- Successfully obtained **H₂-rich and CO-rich streams** from the simulation.  
- Validated that Aspen Plus with ELECNRTL method can accurately model **electrolytic syngas production**.  
- Results aligned with expected trends from electrochemical principles.
